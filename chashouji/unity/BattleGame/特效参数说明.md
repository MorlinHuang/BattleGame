# 《查手机》特效与弹幕 —— 改哪个文件

所有数值都在代码里，没有 Inspector 面板、没有 ScriptableObject，也没有预制体引用。
场景整个由 `Director.Awake()` 搭出来，所以空场景也能直接 Play。

---

## 一、想改什么，去哪个文件

| 你想改的东西 | 文件 | 位置 |
|---|---|---|
| 弹幕**飞多快** | `Assets/Scripts/Game/FxTuning.cs` | `SpeedVolley / SpeedSingle / SpeedHeavy` |
| 弹幕**转多快** | 同上 | `SpinVolley / SpinSingle / SpinHeavy` |
| 每发**速度差多大** | 同上 | `JitterVolley / JitterSingle / JitterHeavy` |
| 大礼物**加速度** | 同上 | `AccHeavy`（设 0 就退回匀速） |
| 大礼物**预警多久** | 同上 | `WarnTime` |
| 连珠**几颗、多密** | 同上 | `VolleyGap` + `GIFTS` 表里的 `n` |
| 弹幕**拖尾多长** | 同上 | `TrailBandBack / GhostCount` |
| 弹幕**从多高飞来** | 同上 | `AmmoYMin / AmmoYMax` |
| **顿帧、震动、白闪** | 同上 | `Hit 区` |
| **加一件新礼物** | 同上 | `GIFTS` 表，加一行 |
| 物品**长什么样** | `Assets/Scripts/Game/AmmoView.cs` | 文件最下面的 `ITEM 区` |
| 命中**炸出什么粒子** | `Assets/Scripts/Game/Recipes.cs` | 一个配方一个方法 |
| 粒子**本身怎么画** | `Assets/Scripts/Game/ParticleFx.cs` | 一般不用动 |
| **对抗线**的画法 | `Assets/Scripts/Game/FrontMarkView.cs` | 也可运行时用面板切 |

## 二、三种弹幕样式

样式管的是**节奏与体量**，不是物品。物品可以无限加，样式只有三种。
观众不用认出飞过来的是什么，光看节奏就知道这一发有多重。

| 样式 | 谁用 | 速度 | 特点 |
|---|---|---|---|
| `Volley` 连珠 | 点赞级 | 1400 px/s | 8 颗间隔 70ms，每颗单独判定、单独触发一次小命中 |
| `Single` 单投 | 普通礼物 | 900 px/s | 单件，飞行约 0.6 秒，看得清是什么东西 |
| `Heavy` 重投 | 大礼物 | 850 px/s + 加速 900 | 先闪 0.25 秒三重箭头预警，再加速压过来 |

**重投不要为了"显得重"而调慢。** 屏幕外到对抗线只有六百来像素，620 px/s 的时候
光飞行就要一秒，加上预警共一秒二——中间那大半秒是匀速滑行、画面上什么也没发生，
观众注意力会飘走。分量感靠体量、预警和落地那一下，不靠拖时间。
加速是同一个道理：拖沓的根子在匀速，而单纯调快又会丢掉"看清它是什么"的那一段。

## 三、礼物表 `FxTuning.GIFTS`

一行就是一件礼物，加新礼物只改这里：

```csharp
new Gift { key = "抱枕", from = +1, style = Style.Single,
           item = Item.Pillow, r = 56f, power = 2,
           recipe = Recipe.Feather, gain = 7f },
```

| 字段 | 含义 |
|---|---|
| `key` | 面板上的按钮名 |
| `from` | `+1` 查岗党（女方，在左，往右飞）/ `-1` 灭迹党（男方，在右，往左飞） |
| `style` | `Volley` / `Single` / `Heavy` |
| `item` | 物品画法，对应 `AmmoView` 的 `ITEM 区` |
| `r` | 半宽（像素）。画布宽 960，所以 `r=56` 的抱枕占屏宽约 12% |
| `n` | 连珠的颗数，其它样式忽略 |
| `power` | `1` 点赞级 / `2` 普通礼物 / `3` 大礼物，决定顿帧白闪震动的档位 |
| `recipe` | 命中炸出什么，对应 `Recipes.cs` |
| `gain` | 命中推多少进度。连珠是**每颗**都推 |

当前六件：

| | 查岗党（左） | 灭迹党（右） |
|---|---|---|
| 连珠 | 发卡×8 | 瓜子×8 |
| 单投 | 抱枕 | 游戏手柄 |
| 重投 | 整条被子 | 外卖箱 |

## 四、两条不好违反的规矩

### 1. 明亮底图上，发光加不上去

底图是明亮客厅（浅绿墙、米色地板）。**白色和相加混合在这上面几乎不改变什么。**
所以整套配色是：

- 发光的（`Dot` / `Spark` / `Ring`）一律**高饱和暖橙**，靠色相跳出来
- 实体的（`Chip` / `Star` / 弹幕物品）一律**深色 + 描边**，靠轮廓跳出来

白闪 `FlashBig` 现在是 0.22，再往上人物就开始糊成一片白。暗色战场的玩法能给到 0.5。

原来那根贯穿全屏的对抗线发光柱（`LineMode = 1`）表现力差就是这个原因，
所以默认换成了顶部指针（`LineMode = 3`）。

### 2. 顿帧冻住的是逻辑，不是粒子

- **走 `dt`（会被冻住）**：角色姿态、对抗线、进度、正在飞的弹幕
- **走真实时间（不冻）**：粒子、白闪、震动

爆炸是"刚刚这一下"的可视化，冻住它就迟到一百毫秒，读起来变成
"闪了一下、卡住、然后才炸开"。而正在飞的弹幕是**下一下**的前奏，该跟着一起冻。

对应代码在 `Director.Update()`：

```csharp
float dt = ParticleFx.Tick(raw);   // 顿帧期间返回 0
ParticleFx.Step(raw);              // 粒子：真实时间
AmmoView.Step(dt);                 // 弹幕：逻辑时间
```

## 五、运行时操作

| 操作 | 作用 |
|---|---|
| `1` ~ `6` | 发对应的六件礼物（顺序同 `GIFTS`） |
| 面板上两排礼物按钮 | 同上 |
| 「查岗党 +7 / 灭迹党 +7」 | 跳过飞行的**直击**，调特效时用 |
| 对抗线四档 | `去掉 / 发光柱 / 地面+针 / 只要针`，可随时切 |
| `空格` | 自动演示开关 |
| `A` `D` 或 左右方向键 | 手动推进度 |
| `F1` | 收起面板 |

## 六、与网页版的对应

网页版是这套东西的单一真源，参数名一一对应，两边可以对着调：

| Unity | 网页版 |
|---|---|
| `FxTuning.cs` 的 Ammo 区 | `web/ammo.js` 顶部的 `SPEED / ACC / JIT` |
| `FxTuning.cs` 的 Hit 区 | `web/main.js` 的 `P` 常量 + `impact()` |
| `FxTuning.GIFTS` | `web/main.js` 的 `GIFT` 表 |
| `Recipes.cs` | `web/main.js` 的 `RECIPE` 表 |
| `ParticleFx.cs` | `web/fx.js` |
| `AmmoView.cs` 的 ITEM 区 | `web/ammo.js` 的 `ITEM` 表 |

网页版地址：`http://1.14.252.30:40235/index.html`

网页版还有几个诊断参数，调手感时比肉眼看动画准得多（特效是瞬时的，
单张截图验证不了任何东西）：

- `?ammostrip=10&ammoms=85&ammogift=quilt` —— 一发弹幕从出场到命中，按时间摊开
- `?fxstrip=8&fxms=45&fxpower=3&fxrecipe=feather` —— 一次命中的前后若干毫秒
- `?linestrip=1&p=72` —— 对抗线四种画法并排比

## 七、已知的取舍

1. **物品是代码画的几何剪影**，不是美术贴图。在原尺寸下发卡读作"粉色小件"、
   抱枕读作"粉色方块"，认不出具体是什么。这是有意的分期：先验证节奏（节奏是
   这个功能的全部），物品精度留给后面生图。
   要换贴图的话，把 `AmmoView` 的 `ITEM 区` 那几个方法换成画一个带贴图的四边形，
   飞行逻辑一行都不用动。

2. **弹幕飞行高度随机**，大约四分之一的概率会从脸部高度经过、短暂挡住人物。
   静帧上比较扎眼，动起来只有零点几秒。想避开就调 `AmmoYMin` / `AmmoYMax`。

3. **染色的实现与网页版略有差异**。网页版用 `source-atop` 往角色上叠半透明纯色，
   Unity 这边用相加层 + 同一张帧当遮罩，效果是按角色自身颜色加亮，亮部加得多、
   暗部加得少。读起来更像"被光扫了一下"，方向一致。
