# 《查手机》弹幕礼物 10 秒视频 · 提示词库

> 对象是 `GIFT` 表里那 **8 件游戏物品**，不是 `SHOP` 里的 9 件抖音平台礼物——
> 后者的特效是平台自带的，我们不做。
> 色值全部取自 `ammo.js` 的 `ITEM` 表，视频必须和引擎里飞的是同一个东西。

---

## 零、动手前先定三件事

### 0.1 这批视频给谁用

| 用途 | 背景怎么给 | 要不要角色 |
|---|---|---|
| **A 礼物特效素材**（叠在直播画面上播）| **纯黑** | 不要 |
| **B 美术参考**（指导引擎实现演出）| 客厅底图 | 要，物品砸中角色 |
| **C 玩法宣传片** | 客厅底图 | 要，完整对局感 |

**下面第二节的八条按 A 写**（最常用、最容易复用）。要 B/C 在每条末尾接上
第三节的场景段即可，主体描述一个字不用改。

### 0.2 背景用纯黑，不要用品红幕布抠像

生图那条管线（`chashouji-art` 的品红抠像）**不要照搬到视频上**：AI 视频逐帧的幕布
颜色会漂，边缘抠完带一圈彩边，而物品本身就有粉色和金色，跟品红是邻近色，抠死一片。

**礼物特效的标准做法是纯黑底 + 滤色/线性减淡叠加**，根本不用抠像。代价是纯黑底上
"暗部细节会被叠没"——所以下面每条都特意要求**物品自带亮边和描边**。

> 注意：这跟此前"概念图不要透明背景"的要求不冲突。那条针对的是**概念图**，
> 这里是**特效素材**，两种东西的交付形态本来就不同。

### 0.3 10 秒要拆成两段生成

主流模型单次出 5 秒。每条都给了 A/B 两段，**B 段的首帧描述要接上 A 段的尾帧**
（提示词里已经写死），拼接处才不会跳。用首尾帧功能的话，把 A 段最后一帧喂给 B 段。

## 一、通用前缀与负向（每条都要带）

### 风格前缀（放在每条提示词最前面）

```
2D 日式赛璐璐动画，手绘厚涂上色，清晰的深棕色线稿描边，明亮柔和的高饱和色调，
平涂加少量渐变，二维动画质感，干净利落的硬边光影，不是三维立体
```

### 负向提示词（每条都用同一串）

```
3D渲染, CG, C4D, blender, 皮克斯, 迪士尼三维, 立体质感, 写实, 照片, 真人,
金属反射, 次表面散射, 景深虚化, 运动模糊, 镜头脏污, 文字, 字幕, 水印, logo,
血, 伤口, 刀具, 碎玻璃, 阴森, 恐怖, 暗黑, 低饱和, 灰暗, 杂乱, 畸变
```

**运动模糊必须进负向**——这个项目的帧切换一直是硬切，糊一下就跟引擎里的观感对不上了。
**"3D/立体"那几个词一个都不能省**，视频模型比生图模型更容易滑向三维。

## 二、八条提示词

> 每条格式：【A 段 0~5s】【B 段 5~10s】。两段都要在前面接风格前缀、后面配负向。

---

### 档 1 · 发卡（查岗党 / 左）

> 档 1 是连珠小件，单件展示会很空，所以按"一串连发"处理。
> 这一档其实可以省——它在游戏里每局出现上百次，观众根本来不及看特效。

**A 段 0~5s**
```
纯黑背景。一根粉色发卡从画面左下飞入：细长圆角小棒，主体亮粉色 #ff8fb8，
一端一颗浅粉珠子 #ffd9e8，整体有深棕色描边。发卡快速自转着从左下飞向右上，
拖出一道粉色光带。紧接着第二根、第三根从同样方向飞入，间隔很短，
排成一串斜向的连珠。每根发卡边缘自带粉色光晕。镜头固定不动。
```

**B 段 5~10s**
```
纯黑背景，接上一段：八根粉色发卡已经排成一条斜线飞过画面。它们逐一撞在
画面右侧的一个看不见的界面上，每撞一根就炸开一小簇金黄色五角星和粉色火花，
八下连成一串轻快的"哒哒哒"。最后所有星星缓缓旋转着淡出，画面回到纯黑。
```

---

### 档 1 · 瓜子壳（灭迹党 / 右）

**A 段 0~5s**
```
纯黑背景。一颗深棕色瓜子壳从画面右下弹入：水滴形，两头尖，主体深棕 #6b5136，
壳面中央一道浅米色高光条，深棕描边。瓜子高速翻滚着从右下飞向左上，
拖出一道暖橙色光带。随后第二颗、第三颗紧跟着弹入，间隔极短，排成一串。
每颗边缘有暖橙色光晕。镜头固定不动。
```

**B 段 5~10s**
```
纯黑背景，接上一段：八颗深棕瓜子壳排成一串斜线掠过画面，逐一撞在画面左侧，
每撞一颗炸开一小簇金黄五角星和暖橙火花，节奏轻快连贯。最后星星旋转淡出，
画面回到纯黑。
```

---

### 档 2 · 兔子抱枕（查岗党 / 左）

**A 段 0~5s**
```
纯黑背景。一只方形圆角的兔子抱枕从画面左侧翻滚着飞入：主体奶白色 #fdf2f6，
中间一圈粉色缝线 #ffa0c3，正面两只竖长的粉色兔耳形状 #ffb3cd，深棕色描边，
布料质感柔软蓬松。抱枕缓慢地整体翻转，占据画面中央，边缘有一圈柔和的粉色光晕。
镜头固定，抱枕由远及近，越来越大。
```

**B 段 5~10s**
```
纯黑背景，接上一段：奶白色兔子抱枕撞在画面右侧，整个被压扁变形又弹回，
瞬间炸开漫天白色和浅粉色的羽毛。羽毛又大又轻，打着旋慢慢往下飘，
飘落速度很慢，有明显的左右摇摆。同时一圈粉色冲击波向外荡开。
最后羽毛还在满屏缓缓飘着，画面渐暗。没有火花，没有爆炸感，只有闷闷的一团。
```

---

### 档 2 · 游戏手柄（灭迹党 / 右）

**A 段 0~5s**
```
纯黑背景。一个游戏手柄从画面右侧翻滚着飞入：扁圆形，机身深灰蓝 #3d4450，
左侧一个亮蓝色圆形摇杆 #8fe3ff，右侧一个红色圆形按键 #ff7a7a，深棕色描边。
手柄快速翻转，蓝色摇杆和红色按键在翻转中一闪一闪。整体有一圈冷蓝色光晕。
镜头固定，手柄由远及近冲向画面左侧。
```

**B 段 5~10s**
```
纯黑背景，接上一段：深灰蓝手柄撞在画面左侧，炸开一片深灰和钢蓝色的碎片，
碎片又快又重，带着暖橙色火花向外飞散，落下时干脆利落不拖泥带水。
一圈橙色冲击波向外荡开。碎片和火花在一秒内迅速消失，画面回到纯黑。
```

---

### 档 3 · 玫瑰花束（查岗党 / 左）★ 重点

**A 段 0~5s**
```
纯黑背景。一大束玫瑰花从画面左侧缓慢推进：七朵盛开的玫红色玫瑰 #e63a62，
其中几朵是更亮的粉红 #ff5f86，花心一圈浅粉描边，四片墨绿色叶子 #5f8f57
从花间探出，下面是米杏色的包装纸倒锥 #f7e3cf，全体深棕色线稿描边。
花束缓慢地整体旋转，由远及近变大，边缘有一圈玫红色光晕，
零星金色光点在花瓣间闪烁。镜头固定，节奏舒缓而有分量。
```

**B 段 5~10s**
```
纯黑背景，接上一段：玫瑰花束撞在画面右侧，整束炸开，漫天玫红色和亮粉色的
花瓣向外爆开。花瓣是一片片带深红描边的椭圆，又大又清晰，打着旋极慢地
飘落，左右摇摆幅度很大。花瓣之间夹杂少量金色光点。
一圈玫红冲击波荡开。十秒结束时花瓣仍在满屏飘落，画面渐暗。
```

### 档 3 · 奶茶（灭迹党 / 右）★ 重点

**A 段 0~5s**
```
纯黑背景。一杯奶茶从画面右侧翻滚着飞入：上宽下窄的梯形塑料杯，
奶茶液体焦糖色 #e8c9a0，杯底沉着一层深褐色珍珠 #4a3324，
杯口一片米白色封膜 #fff4e4，一根粉色吸管 #ff8fb8 斜插着穿过封膜，
深棕色描边。杯子在空中翻转，杯里的液体和珍珠随着翻转晃动。
边缘一圈暖橙色光晕。镜头固定，杯子由远及近冲向画面左侧。
```

**B 段 5~10s**
```
纯黑背景，接上一段：奶茶杯撞在画面左侧，焦糖色的奶茶整杯泼出去，
泼成一大片浓稠的琥珀色浆液，糊住一片并停在原地缓慢流淌。
同时几十颗深褐色的圆形珍珠四处弹跳飞散，珍珠又圆又实，带深色描边，
弹跳感强。琥珀色的糖浆丝向外拉出细线。一圈焦糖色冲击波荡开。
珍珠继续弹跳，糖浆挂着不动，画面渐暗。
```

### 档 4 · 求婚戒指盒（查岗党 / 左）★★ 最高档

**A 段 0~5s**
```
纯黑背景。一个求婚戒指盒从画面左侧缓缓压过来，速度很慢很有压迫感：
玫红色丝绒方盒 #d4527d，盖子已经掀开向后仰，盖子内衬浅粉 #ffe6ef，
盒里深红色绒布槽 #8f2d4f 上立着一枚金色戒指 #ffd35a，
戒指上一颗菱形的冰蓝白钻石 #eaf7ff 不断闪烁出十字星光。
深棕色描边。盒子极缓慢地旋转推进，体积越来越大占满画面，
周围金色光点向上飘浮。镜头固定，气氛庄重而甜。
```

**B 段 5~10s**
```
纯黑背景，接上一段：戒指盒撞在画面右侧的瞬间，钻石爆出一团强烈的金色闪光，
三圈金色和粉色的光环依次由内向外快速荡开，一圈比一圈大。
同时几十颗粉红色的心形从撞击点向四面八方炸开，心形带深红描边，
先向外冲开一圈，然后全部缓缓向上飘升，边飘边左右摇摆。
心形之间夹杂旋转的金色五角星和金色光粉。
十秒结束时爱心仍在向上飘，画面渐暗。整体是绽放感，不是爆炸感。
```

纯黑背景。一个竖长的木质相框从画面右侧缓缓压过来，速度很慢：
相框边缘暖棕木色 #b8864f，里面米白色相纸 #fdf6ea，
相纸上是两个肩膀挨在一起的蓝灰色剪影人像 #7d93b5，没有五官，

## 三、要"带场景版"就接这一段

把下面这段接在上面任意一条的**主体描述之后**，并把"纯黑背景"四个字删掉：

```
场景是一间明亮的客厅：浅豆绿色墙面，米色木地板，浅绿色地毯，灰色布艺沙发，
沙发上放着一只黑猫抱枕和一只白兔抱枕，左侧有绿植和木质边柜，右侧有落地灯。
午后阳光从右侧照进来，在墙上投出窗格和植物的影子。
画面左边站着一个女生：长直黑发，右侧别一朵红色小花，穿粉色兔子图案睡衣，
白色兔子拖鞋。画面右边站着一个男生：黑色短乱发，白色短袖T恤，
黑色侧条纹运动裤，黑色猫咪拖鞋。两人正各拉着一部手机的一端用力互拽，
表情又急又倔。物品从（左/右）侧飞来，砸在（男生/女生）身上。
```

**必须同时补进负向**：`性别对立, 暴力, 打人, 受伤, 表情狰狞`

拽手机的姿势一定要写进去——这是这个玩法的**唯一核心画面**，少了它就只是两个人站着。

## 四、参数

| 项 | 取值 |
|---|---|
| 画幅 | **9:16 竖屏**，1080×1920 |
| 帧率 | 24 或 30（跟引擎的 30 对齐更省事） |
| 单段时长 | 5s ×2 段拼成 10s |
| 运镜 | **全部固定机位**。物品自己动就够了，镜头再动会看不清物品是什么 |
| 首尾帧 | B 段用 A 段末帧起手，接缝才不跳 |

## 五、英文模型（Runway / Veo / Sora）改写要点

不要直译，换三处：

1. 风格前缀换成：`2D cel-shaded anime animation, hand-painted, clean dark brown
   line art, bright saturated palette, flat colors with soft gradients, no 3D`
2. 负向里 `3D render, CGI, Pixar style, photorealistic, motion blur, depth of field`
   这几个是必须的，其余可删
3. **色值 hex 英文模型基本不认**，改写成颜色词：`#e63a62` → `deep rose red`，
   `#e8c9a0` → `caramel milk tea beige`，`#4a3324` → `dark brown tapioca pearls`

## 六、出片之后怎么验收

按这五条挑，不过就重生成，别凑合：

1. **是不是二维**——有没有塑料光泽、立体投影、金属反射。这是最容易翻车的一条。
2. **物品认不认得出**——不看提示词的人能不能一眼说出这是什么。
   档 4 的戒指盒尤其要盯：引擎里做的时候它一度读成"两个粉方块"。
3. **颜色对不对得上引擎**——拿视频某一帧和网页版截图并排比。
4. **有没有血腥恐怖的暗示**——炸开的东西必须读作"要收拾一下"，不是"要送医院"。
5. **档位分得开吗**——把八条排在一起看，档 1 到档 4 的分量差是不是一眼能排序。
   分不开就是白做，这正是《礼物设计.md》第二节那张表想解决的问题。
