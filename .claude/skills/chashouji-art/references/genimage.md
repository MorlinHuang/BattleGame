# 《查手机》生图：已定稿的构图结论

概念图历史在 `/workspace/art/chashouji/v2/ … v9/`。下面是十轮迭代后**留下来的结论**，
再出图（补帧、出物品、改构图）时直接用，不要重走一遍。

## 定稿构图：v8_A

`/workspace/art/chashouji/v8/v8_A_phone_bubble.png` —— 用户认可"最符合要求"。

要素：7 头身青年动漫比例 / 手机缩到接近正常尺寸（约头长）/ **聊天内容外挂成漂浮
大气泡**（引线连回手机）/ 中央垂直对抗光柱 + 白色刻度 / 居家客厅 / 顶部
查岗党·灭迹党 HUD / 底部「开始游戏 LOVE BATTLE」。

**气泡外挂这个设计是从"手机太小看不清字"逼出来的**，后来在网页版落地成了
`bubble.js`——它同时解决了"手机屏内容烧死在帧里"这个关键帧路线的代价。

## 道具体积：用角色头长当标尺

v7 把手机画到角色身高 30%（现实仅 9%），用户判"过于大"；缩到略小于头长又会让
四只手挤成一团、拉扯动作读不出来。**合适值 ≈ 头长的 1.2~1.5 倍。**

体积不够导致读不出内容时，用"外挂大气泡 + 引线"解决，不要放大道具本身。
**iPad 方案被比下去**：平板体积自洽、屏幕字清楚，但平板是共用设备、私密感弱，
与玩法名《查手机》对不上。

## 画风：螂人杀参照，30-40 岁受众

用户明确：整体美术参考**螂人杀**，主要用户 **30-40 岁**。落地到 prompt 的关键词
（已验证一次到位）：

- 纯 2D 扁平卡通 + 粗黑描边 + **大色块平涂**
- 背景 = **不透明纯色实底**（浅米色墙面一块 + 地面左绿右红两块，仅此）
- 角色 = **成年人形象**，明确写"不要少女感、不要二次元萌系"
- 禁止：细碎纹理 / 花纹图案 / 噪点 / 杂物堆 / 密集小物件 / 透明背景 / 棋盘格背景

**v5 是反面教材**（居家客厅狼藉 + 花纹地毯 + 满地零食），元素碎到无法拆件。

## 跨档一致性：体型不能崩

出五档阶段图（v9：优势 95/75/50/25/5）时，只写"蹲伏/劣势"会让模型把弱势方
**整体缩小成儿童比例**，同一角色跨档就不是同一个人了，帧对齐直接失效。
必须显式写死：

> 身体尺寸、头身比、肩宽、四肢长度与对方完全相同，都是七头身成年人；
> 劣势只通过姿势和表情表现，不通过缩小体型表现。

**用定稿图当参考图做 image-to-image** 是保住服装、发型、发饰、拖鞋的唯一手段。

## 对抗线表达

光柱从垂直变**倾斜压向劣势方**，优势色面积扩到 3/4 或 9/10，劣势色被挤成边缘细缝。
不看数字光看配色就知道战况。

**但白色刻度尺在所有阶段图里都丢失，极端档光柱退化成弧形亮边** ——
结论：**HUD 数值条与刻度一律程序绘制叠加，不回炉重画美术。**

## 文字：一律程序绘制

中文短词渲染是模型的稳定短板。实测「查岗党/灭迹党」被写成「宣闸克/灭逊克」
「查网完/火遍完」。近期有变好，但量产一律程序绘制。

反过来**模型自创的文案要收**，已收编的有：礼物名「发送假证」、主标题
「情感争夺战 / 谁掌控TA的聊天记录?」、按钮「开始对抗」。

## 已被否掉的方案（不要再提）

- **铁证卡（红卡闪烁）**：3 级证据里的最高级，用户拒绝。
- **聊天内容打马赛克/模糊**：用户要求"聊天内容不能模糊，要有代入感"。
  代入感靠**日常短句 + 观众自己补全**，不靠露骨内容也不靠遮挡。
- **对抗线压在手机上当另一层光柱**：两图层抢注意力，这是 v3 阶段诊断出的根因。
  解法是合体（手机位移本身即对抗线）。

## 生图服务的两种失败

- **对特定参考图稳定失败**（上游 502 指名某个 sha256）——这里是 f095/f100 那两张
  "男方跪地"的构图，重新编码换哈希也没用，只能换参考图。
- **服务级 503**（熔断退避）是另一回事，等半分钟重试即可。
