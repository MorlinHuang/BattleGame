# 《查手机》项目 skill

这六个 skill 把这个项目的做法、踩过的坑和验收标准固化下来，
让接手的人（和下一次的我）不必从零重走一遍。

## 怎么生效

**方式一（推荐）**：在仓库根 `/workspace/art` 打开 Claude Code，
项目级 skill 自动被发现，直接 `/chashouji` 调用。

**方式二**：装到个人目录，任何位置都能用。

```bash
cp -r .claude/skills/chashouji* ~/.claude/skills/
```

## 六个分别管什么

| skill | 管什么 | 什么时候会自动命中 |
|---|---|---|
| `chashouji` | 项目总览与导航 | 提到"查手机""查岗党/灭迹党""BattleGame" |
| `chashouji-art` | 生图、品红抠像、89 档关键帧 | "抠图""紫边""补一张帧""插帧""出物品素材" |
| `chashouji-web` | 网页代码结构与改法 | "改网页""加一件礼物""调数值""部署" |
| `chashouji-fx` | 特效与打击感 | "加特效""发光看不见""表现力差""连点卡顿" |
| `chashouji-verify` | 怎么看到效果、怎么拿到数 | "看看效果""截个图""压测一下" |
| `chashouji-unity` | 同步 Unity、出 exe | "同步到 Unity""出个 exe""打包后没了" |

**不确定从哪开始就读 `chashouji`**，它末尾有一张"要干什么去看哪个"的表。

## 每个都有一节「开工前必须问清」

这是这套东西真正值钱的地方——答错的代价是整段返工。最关键的三条：

- **角色走预渲染关键帧，不走骨骼动画。** v10~v12 的网格变形已被否掉
  （用户原话："spine 效果还是太差了"）。不要回头。
- **配色由底图亮度定。** 这张明亮客厅底图上 `lighter` 整条通道失效，
  发光只能靠色相、实体只能靠轮廓。
- **网页版是单一真源。** Unity 逐字对照搬，且要等用户说"这个特效没问题"才搬。

## 维护

改了做法就改对应的 skill，它写错了比没有更糟。
已经发生过一次：通用版里的 Unity 文件对应表写着四个早已删掉的文件——
**照着 `ls` 出来的真实清单写，不要照着记忆写。**
